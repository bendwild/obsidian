# 1. Conditional probability
```
P(A∩B)=P(A) P(B|A)
P(A∩B)=P(B) P(A|B)
P(A∩B)=P(A) P(B|A) -> P(B│A)=(P(A∩B))/(P(A)) 
P(A∩B)=P(B) P(A|B) -> P(A│B)=(P(A∩B))/(P(B))
```

# 2. Bayes’ Theorem
→ using the multiplicative rule of probability

```
P(A∩B)=P(B) P(A|B)
P(A∩B)=P(A) P(B|A)
P(B) P(A|B) = P(A) P(B|A) -> P(A│B) = (P(A) P(B|A))/(P(B)) 
P(B) P(A|B) = P(A) P(B|A) -> P(B) = P(A) P(B|A) + P(B|notA) P(notA) -> P(A│B)=(P(A) P(B|A))/P(B|A)P(A) + P(B|not A) P(not A)
```
