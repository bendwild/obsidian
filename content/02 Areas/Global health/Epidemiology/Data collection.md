# Data collection methods

|                                              | Pro                                                                                                       | Con                                                                         | Example                          |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | -------------------------------- |
| **Mailed surveys**                           | - easy to use<br>- low tech / accessible<br>- safe                                                        | - low response rates<br>- blank responses<br>- what if people have moved?   |                                  |
| **Telephone interviews**                     | - room to explain the questions<br>- fewer blank responses<br>- cheaper & safer than in-person interviews | - can be difficult to get response<br>- somewhat impersonal                 |                                  |
| **In-person interview**                      | - room to explain the questions<br>- fewer blank responses<br>- more personal                             | - difficult to arrange<br>- costly<br>- safety should be considered         |                                  |
| **Direct observation (etnography)**          |                                                                                                           |                                                                             |                                  |
| **Electronic survey**                            | - easy data aggregation<br>- can reach wide audience quickly                                              | - requires internet access<br>- potential for low response rate             | - google forms<br>- surveymonkey |
| **Computer-assisted personal interviews (CAPI)** | - real-time data entry<br>- less room for interviewer [[bias]]                                                | - requires devices<br>- potential technical issues                          |                                  |
| **Environmental monitoring**                     |                                                                                                           |                                                                             |                                  |
| **Mobile apps**                                  | - real- time data entry<br>- geolocation capabilites<br>- multimedia integration                          | - requires smartphones/tablets<br>- potential issues regarding data privacy | - Epi info<br>- opendatakit      |
| **SMS Surveys**                                  | - wide reach                                                                                              | - limited by text length<br>- low response rates                            |                                  |
| **Wearables**                                | - continuous data monitoring<br>- user-friendly                                                           | - expensive<br>- data reliability issues                                    |                                  |
| **Remote sensing**                           | - spatial data collection<br>- monitoring environmental factors                                           | - requires expertise<br>- potential privacy concerns                        |                                  |
| **Databases and registries**                 |                                                                                                           |                                                                             |                                  |
| **Medical records**                          |                                                                                                           |                                                                             |                                  |
| **Biomarkers**                               |                                                                                                           |                                                                             |                                  |

> [!INFO] Key factors in deciding
> - population
> - location
> - budget 
> - data quality
> - current literature 

## Primary vs Secondary data sources
|                    | Pro                                                                                                           | Con                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Primary data       |                                                                                                               |                                                                                   |
| **Secondary data** | - efficiency<br>- time-saving<br>- large sample sizes<br>- longitudinal analysis<br>- faster ethical approval | - potential [[bias]]<br>- missing data<br>- not tailor-made<br>- quality concerns |

> [!ATTENTION] Considerations when using secondary data
> - validity?
> - relevance?
> - accessibility?
> - updates?


## Open- vs closed ended questions

|                            | Pro                                                                                                                                                                                          | Con                                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Closed-ended questions** | - simple to transfer to database and code for data analysis<br>- simple to convert to a variable for statistical analysis<br>- different interviewers will likely interpret things similarly | - loss of information<br>- true answers may not always be so simple<br>- sometimes forces people into giving their best guess |
| **Open-ended questions**   |                                                                                                                                                                                              |                                                                                                                               |

# How to reduce errors in the data
 - use standardized methods
 - pilot tests
 - train and evaluate your staff
 - take multiple measurements
 - use validated or widely accepted methods
 - institute quality control procedures
