# Bounded rationality
> = have the relevant information on available options, but fail to make the optimal decision

| Concept                                  | Explanation                                                                                                                 | Example                                                                                                                |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Anchoring**                            | Often latch onto something (first thing heard, midpoint or endpoint)                                                        |                                                                                                                        |
| **Loss and regret aversion**             |                                                                                                                             |                                                                                                                        |
| **Affect heuristic**                     | Emotions influence behaviors                                                                                                | When male college students were aroused, they were more willing to engage in unsafe sex than when in neutral state.    |
| **Limited attention**                    |                                                                                                                             |                                                                                                                        |
| **Optimism and overconfidence**          | Tendency to under- or overweight events despite statistics or won experience                                                | Physicians overtest low risk patients and undertest high risk patients / overweight certain symptoms (e.g. chest pain) |
| **Salience, recency, availability [[bias]]** | Overweighting things that occurred more recently, you better relate to, or are more available in the immediate surroundings | Flying after plane crash                                                                                               |
| **Confirmation [[bias]]**                | Only seek out information that supports your position                                                                       |                                                                                                                        |
| **Reference dependence**                 |                                                                                                                             | Kenyan bicycle taxi drivers’ labor supply respond positively to cash needs                                             |
| **Representativeness**                   | Tendency to use mental shortcuts by categorizing observed patterns                                                          |                                                                                                                        |
| **Priming**                              | Being exposed to a stimuli and unconsciously making connections with something else                                         |                                                                                                                        |
| **Status quo [[bias]] (defaults)**       | If making an active decision involves too much effort, then tend to default to the status quo                               |                                                                                                                        |
| **Framing**                              | Punishments or rewards?                                                                                                     | Higher surgery uptake described as improved survival vs reduced mortality                                              |
