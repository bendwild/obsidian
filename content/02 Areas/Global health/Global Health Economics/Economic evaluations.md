> = the comparative analysis of alternative courses of action in terms of both their costs and consequences [[@Michael Drummond]]

# The need for economic evaluations
1. Scarcity of resources
	1. growth in health expenditure is higher than growth rate
	2. evolution towards post-mature societies
	3. economists also need to think about the best alternative use of resources (= **opportunity cost**)
2. Every country has their own healthcare crisis
3. Decisions need to be based on comparison of costs and benefits
4. Efficiency is not the same as cost-cutting

# When is an economic evaluation applicable?
After implementation of: 
- efficacy studies
- effectiveness studies

> [!ATTENTION] Generally a [[cost-effectiveness analysis]] is **not** needed
> - CAVE a cost-minimization analysis may be appropriate

# What is an economic evaluation
|                                            | Only outcome                                                                               | Only cost                                   | Both outcome and cost                                                                                                                                                                                                              |
| ------------------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No comparison**                          | Outcome description                                                                        | Cost description                            | Cost-outcome description                                                                                                                                                                                                           |
| **Two or more alternatives were compared** | Efficacy/effectiveness evaluation (fe clinical trials, comparative effectiveness research) | Cost evaluation (eg budget impact analysis) | Full economic evaluation<br>- cost-minimization analysis (same outcome)<br>- [[cost-effectiveness analysis]] (non-monetary outcome)<br>- cost-utility analysis (utility-based outcomes)<br>- cost-benefit analysis (monetary outcomes) |
   

|                                     | Definition                                                                                                           | Characteristics                                                                                                                                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[[Cost-effectiveness analysis]]** | = comparison of value for money of alternative health programs                                                       | - one-dimensional measure<br>- non-monetary outcome (life years gained, infections avoided)<br>- results expressed as **incremental cost per effect gained**<br>- allow for compariso**n within disease areas**     |
| **Cost-utility analysis**           | = specific type of CEA                                                                                               | - outcomes measured as utility values (QALY/DALY)<br>- results expressed as incremental cost per QALY gained/DALY averted<br>- broader than CEA (facilitates comparison of treatments for **different conditions**) |
| Budget Impact Analysis              | = addresses the expected changes in the expenditure of a health care system after the adoption of a new intervention |                                                                                                                                                                                                                     |

> [!INFO] What is a QALY?
> = quality-adjusted life year
> = time (years) x quality (utility)
> = theoretically exact opposite of DALY (1 QALY = 0 DALY)
